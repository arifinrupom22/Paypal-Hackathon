## Brand & Style

This design system establishes an institutional-grade, zero-trust cryptographic visual language tailored for autonomous agent execution and programmatic capital allocation. The visual narrative combines the cold rigor of sovereign cryptography with the refined ergonomics of mission-critical financial engineering platforms.

### Strategic Personality
- **Cryptographic Authority:** Precise, unwavering, verifiable. Visual patterns reject whimsical decor in favor of clear structural boundaries, immutable state indicators, and mathematically governed data presentation.
- **Cognitive Clarity under Latency:** Interfaces convey high-frequency mandate validation, deterministic authorization pipelines, and policy enforcement at sub-millisecond perception.
- **Enterprise Bank Sovereignty:** Evoking the quiet permanence of institutional vaults and defense infrastructure rather than consumer neo-banking.

### Aesthetic Methodology
The aesthetic movement fuses **Modern Technical Minimalist** and **Engineered Glassmorphism**:
- Deep midnight backdrops set the canvas for tiered architectural planes.
- Micro-engineered data displays feature hairline containment borders (`1px`), hairline dividers, and subdued radiant backlights that denote cryptographic verification states (e.g., Ed25519 signature verified, threshold consensus achieved).
- Decorative ornamentation is replaced with structural integrity: monospace telemetry, high-contrast semantic indicators, deterministic hierarchy, and deliberate structural density.

## Colors

The palette establishes an absolute contrast baseline optimized for prolonged monitoring environments, operations centers, and low-latency audit dashboards.

### Canvas & Surface Architecture
- **Base Canvas (`#080D18`):** Deep midnight navy base absorbing visual noise and establishing spatial depth.
- **Base Elevation Surface (`#101827`):** Primary tier for modular authorization cards, policy matrices, and ledger feeds.
- **Interactive Surface / Hover State (`#162236`):** Applied on active state inspections, drawer panels, and elevated nested lists.
- **Structural Outlines & Grids (`#1E293B` to `#202D40`):** Precise bounding lines separating cryptographic pipelines and data partitions.

### Deterministic State Tokens
- **Electric Teal (`#14D6B0`):** Primary operational token. Used for active mandates, primary actions, algorithmic routing nodes, and cryptographic proof checkpoints.
- **Emerald Green (`#10B981`):** Verified execution token. Denotes `AUTHORIZED`, consensus settlement, valid cryptographic key signatures, and verified autonomous transactions.
- **Amber Warning (`#F59E0B`):** System friction token. Denotes `REQUIRES_APPROVAL`, budget soft-limit thresholds, anomaly alerts, and human-in-the-loop review triggers.
- **Crimson Red (`#EF4444`):** Hard perimeter rejection token. Denotes `BLOCKED`, `REVOKED`, zero-trust rule violations, signature mismatches, and automated fail-safes.

### Contrast Hierarchies
- **Text Primary (`#F8FAFC`):** Primary interface directives, critical balances, and mandate state labels.
- **Text Secondary (`#94A3B8`):** Metadata markers, policy constraints, parameter names, and tabular cell data.
- **Text Muted (`#64748B`):** Monospace hashes, timestamps, inactive parameter labels, and non-interactive structural framing.

## Typography

Typography enforces a strict duality between human-readable governance instructions and deterministic programmatic payloads.

### Type Pairings
- **Geist (Headlines & Body):** Employs calibrated mechanical tracking, cold geometric curves, and neutral legibility across operational views and configuration forms.
- **JetBrains Mono (Identifiers, Ledger Payloads, & Security Badges):** Employs fixed character widths for hex addresses, Ed25519 signatures, UUID mandate keys, and transaction payload strings. Prevents layout drift in high-velocity tabular data feeds.

### Usage Standards
- Display titles use tight negative tracking (`-0.03em` to `-0.015em`) for modern corporate authority.
- All status tags, cryptographic verification labels, mandate IDs, currency representations, and audit timestamps render strictly in `JetBrains Mono` with uppercase tracking (`letter-spacing: 0.04em` to `0.06em`).
- Numeric monetary figures and budget ceilings use tabular numbers (`font-variant-numeric: tabular-nums`) to maintain alignment during real-time balance fluctuations.

## Layout & Spacing

The structural layout enforces mathematical predictability through a disciplined 8px baseline rhythm across all horizontal and vertical alignments.

### Grid Framework
- **Desktop (>= 1280px):** 12-column fluid grid system bounded by a max container width of `1600px`. Gutters are locked at `1.5rem` (`24px`), margins at `2rem` (`32px`). Element spans operate strictly in symmetric modules (2, 3, 4, 6, 8, or 12 columns).
- **Tablet (768px - 1279px):** 8-column layout with `1rem` (`16px`) gutters and `1.5rem` (`24px`) canvas margins. Side-by-side verification flows stack into 4-column modules.
- **Mobile (< 768px):** 4-column layout with `0.75rem` (`12px`) gutters and `1rem` (`16px`) margins. Deep cryptographic audit trees collapse into single-column vertical disclosure panels.

### Structural Flow
- Internal component paddings reference tokens `space-sm` (`8px`) and `space-md` (`16px`) for micro-surfaces (e.g., status pill counters, policy rows) and `space-lg` (`24px`) for card interiors.
- Sections, mandate inspection panels, and runtime stream timelines maintain `space-xl` (`32px`) separating boundaries.

## Elevation & Depth

Visual hierarchy uses tonal surface stacking paired with sharp, low-opacity structural borders. Physical skeuomorphic drop shadows are eliminated in favor of subtle radiant light conduits denoting security and consensus states.

### Surface Tiers
- **Level 0 (Canvas Base - `#080D18`):** System backdrop. Houses layout rails, ambient structural lines, and static viewport edges.
- **Level 1 (Structural Containers - `#101827`):** Primary platform containers, ledger grids, policy cards, and execution panels. Framed with a 1px border of `#202D40`.
- **Level 2 (Active Sub-surfaces & Popovers - `#162236`):** Filter arrays, expanded mandate inspection drawers, nested payload trees, and dropdown menus. Framed with a 1px border of `#1E293B`.
- **Level 3 (Modal Dialogs & Critical Interventions):** `#101827` overlaid on an `#080D18` backdrop blurred at `12px` (`backdrop-filter: blur(12px)`), bordered with high-contrast `#202D40`.

### Security Glow Conduits
Depth under state change is expressed using subtle, low-spread ambient glows:
- **Verified / Authorized:** `box-shadow: 0 0 16px -4px rgba(20, 214, 176, 0.15);`
- **Requires Attention / Review:** `box-shadow: 0 0 16px -4px rgba(245, 158, 11, 0.15);`
- **Blocked / Rule Violation:** `box-shadow: 0 0 20px -2px rgba(239, 68, 68, 0.20);`
- **Inactive / Quiescent:** Zero shadow elevation; strictly structural 1px border contrast.

## Shapes

The shape system balances modern software ergonomics with engineering precision through a disciplined corner curve hierarchy.

### Geometry Hierarchy
- **Micro UI Elements (`rounded` - 4px to 6px):** Checkbox boxes, inline cryptographic pill tags, data table cell tags, and scroll tracks.
- **Core Components (`rounded-md` - 8px):** Action buttons, input fields, verification chips, code payload containers, and mandate parameter rows.
- **Major Containers (`rounded-lg` - 12px):** Data tables, flow diagram panels, policy orchestration cards, drawer panels, and modal shells.
- **Circular Elements (Fully Rounded):** Identity avatar fallbacks, status pulse indicators, and radial network diagram nodes.
